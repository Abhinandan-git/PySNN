# 🧠 Neural Network from Scratch

A fully connected feedforward neural network implemented from the ground up in Python, without using machine learning libraries like TensorFlow, PyTorch, or scikit-learn. This project is intended for educational purposes, offering a hands-on approach to understanding the mathematics and mechanics behind neural networks.

---

## 🔍 Features

- No external ML libraries used – only NumPy
- Custom implementation of:
  - Forward propagation
  - Backpropagation
  - Gradient descent optimisation
  - Loss functions (e.g., MSE, Cross-Entropy)
  - Activation functions (ReLU, Sigmoid, Tanh, etc.)
- Support for multiple hidden layers
- Train and evaluate on real datasets (e.g., XOR, MNIST, etc.)
- Modular, extensible architecture

## 🚀 Getting Started

- Python 3.8+
- NumPy

### Installation

```bash

cd neural-network-from-scratch
pip install -r requirements.txt
````
